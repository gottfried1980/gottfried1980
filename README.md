## Woran ich arbeite

**GANCPT** — ein dauerhaftes Gedächtnis für KI-Agenten. Jede Aussage zeigt auf die Stelle, aus der sie
stammt; was sich nicht belegen lässt, wird als Lücke gezeigt, nicht überspielt. Läuft lokal, ohne
Cloud-Pflicht, und rechnet sich aus seinem eigenen Ereignisstrom jederzeit neu.

> *belegt, nicht behauptet.*
